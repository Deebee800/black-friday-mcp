Amazon MCP Server for Shopping

Black Friday MCP is a free, independent remote MCP server for Amazon.com shopping. It is separate from Amazon's AWS and Ads MCP servers. Add https://blackfridaymcp.com/mcp to Claude Code, Cursor, Codex, Claude or ChatGPT. It returns live in-stock prices, Amazon's discount labels and the product link. You don't need an Amazon login, cookies or an API key.

Its four read-only tools are search_deals, check_deal, get_trending_deals and gift_ideas.

How the Amazon MCP server works

Check these before you add it.

Endpoint
Streamable HTTP at https://blackfridaymcp.com/mcp. Nothing to install.
Auth
OAuth 2.1 with PKCE, dynamic client registration and client ID metadata documents. One-click consent creates an anonymous install ID.
Access
Read-only. The tools cannot place orders.
Data
Amazon's Creators API, the official affiliate API. No scraping. Amazon.com (US) only, prices in USD.
Registry
Listed in the official MCP Registry as com.blackfridaymcp/deals.
Caching
Prices up to 1 hour, everything else up to 24 hours.
Cost
Free. Black Friday MCP earns an Amazon affiliate commission when you buy through its links.

Three things called Amazon MCP

A search for "Amazon MCP" returns three kinds of servers.

AWS MCP servers

For cloud work. They let an assistant read AWS documentation and manage AWS resources.

Most need AWS credentials

Amazon Ads and seller MCPs

For sellers and advertisers. They connect an assistant to a seller or Ads account to manage campaigns and listings.

Needs a seller or Ads account

Shopping MCPs

For buyers. They search products and prices. Black Friday MCP is one.

Black Friday MCP needs only the URL

As of November 2026, we found no official Amazon MCP server for shoppers.

Questions developers ask

Does Amazon have an official MCP server?

+

Yes, for AWS cloud work and for Amazon Ads. Black Friday MCP is not made by Amazon. It uses Amazon's official Creators API and earns as an Amazon Associate, but Amazon does not run or endorse it.

Do I need an Amazon account or API key?

+

No. The server calls Amazon with its own Creators API credentials. You approve one consent screen and get a token that lasts 30 days. You sign in to Amazon only to buy.

Which Amazon stores does it cover?

+

Only Amazon.com in the US, with prices in USD. check_deal rejects links from other Amazon stores, such as amazon.co.uk. It cannot expand a.co or amzn.to short links, so paste the full product URL.

Does it store my searches?

+

Results are cached for up to 24 hours, and search terms are kept for up to 24 hours after their last use. Neither is linked to your install ID, which is random and used only for rate limits and a daily count. Server logs are kept for up to 7 days.
