An MCP is an add-on for your AI assistant, the way an app is an add-on for your phone. Black Friday MCP adds the skill to look up Amazon prices and deals. Paste one address, click Connect, done. Nothing to download, nothing to log into.

For developers

Remote MCP server over Streamable HTTP. OAuth 2.1, no API key.

Endpoint and transport+
POST https://blackfridaymcp.com/mcp
MCP 2026-07-28, stateless; older stateless clients supported
Auth: OAuth 2.1 bearer token, scope shop:read

Unauthenticated requests get a 401 with a WWW-Authenticate challenge, so any compliant client discovers the flow on its own.

Authorization+
Dynamic client registration at /oauth/register; client ID metadata documents accepted.
PKCE S256 required. Loopback redirect URIs with any port accepted.
Consent is one click and mints an anonymous install ID. No user accounts.
Access tokens last 30 days. Resource metadata at /.well-known/oauth-protected-resource/mcp.
Tools+
search_deals { query, max_price?, min_discount_percent?, category?, prime_only? }
check_deal { asin_or_url }
get_trending_deals { category?, max_price? }
gift_ideas { budget, ideas[1..3], recipient?, occasion? }

All four are read-only. Full field lists and an example response on the Developers page.

Limits+
Per connection: 150 Amazon lookups per day, 10 uncached lookups per minute, about 60 requests per minute burst.
Cached answers do not count. Prices are cached up to 1 hour, everything else up to 24 hours.
Responses aim for under 5 seconds, with a hard ceiling of about 9 seconds.
Rules the server follows+
Amazon links pass through exactly as vended. No shorteners, no added parameters.
No scraping. Everything comes from Amazon's Creators API.
No stored price history. Discount evidence comes from Amazon's own reference price for each item.
US marketplace only, prices in USD.

What is Black Friday?

+

The Friday after US Thanksgiving and the start of the holiday shopping season, when retailers run their biggest discounts of the year. Deals now start earlier in November and run through Cyber Monday.

What is an MCP?

+

A connector built on the Model Context Protocol, an open standard that lets AI assistants use outside tools. Black Friday MCP adds live Amazon prices and deals.

How do I use Black Friday MCP if I never used AI?

+

Open any AI assistant you already have: Claude, ChatGPT, Gemini, or Grok. Follow the three steps in the Beginner's guide. Then type what you would say to a friend, such as "Black Friday deals on air fryers under $100?" The assistant does the rest and shows links to Amazon.

When is Black Friday in 2026?

+

Friday, November 27, 2026. Cyber Monday is November 30. Amazon's Black Friday deals usually start in the second half of November.

Why are products discounted on Black Friday?

+

Retailers use the biggest shopping days of the year to win holiday spending and clear inventory, and manufacturers fund discounts to move volume. Some discounts are real. Others are measured against inflated list prices, which is why the reference price matters.

How do I know if a deal is real on Black Friday?

+

Look at what the discount is measured against. A price below the item's lowest recent price is a real drop. A "was" price is Amazon's own reference and points to a likely discount. A percent off a "list price" is weak evidence, because list prices often sit above the usual selling price. Black Friday MCP labels every discount this way, and the check tool gives a one-line verdict for any Amazon link.
