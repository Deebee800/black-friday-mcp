What to look for in a mechanical keyboard

Check these six things before you buy.

Layout
75% keeps the arrows and F-row for IDE shortcuts like F5 to debug. TKL adds the full Home, End and Page Up/Down block. 65% drops the F-row. 60% drops the arrows too. Full-size adds a numpad.
Switches
Tactile switches have a bump. Linear ones move straight down. Clicky ones add a click mics pick up. For calls and shared offices, pick silent linear or quiet tactile.
Hot-swap
Hot-swap sockets let you change a switch without soldering. Most take MX-style switches. Low-profile boards need low-profile switches and keycaps.
QMK and VIA
QMK is open-source keyboard firmware, and VIA remaps a supported QMK board live. Put brackets and arrows on a layer, or turn Caps Lock into Escape.
Connection
Wired USB-C has the lowest latency and no battery. Many Bluetooth boards pair with 3 devices. A 2.4 GHz receiver has lower latency than Bluetooth.
Mac or Windows, ANSI or ISO
Many boards have a Mac/Windows switch, and some ship both sets of keycaps. ANSI is the US layout with a wide Enter. ISO has a tall Enter and a short left Shift.

Questions developers ask

Is a mechanical keyboard worth it for programming?

+

Yes, if you type for hours a day. Each switch is rated for tens of millions of presses, and worn keycaps can be replaced.

75% or TKL for coding?

+

Pick 75% if you want the mouse closer, since it is 1 to 2 inches narrower. Pick TKL if you use Home, End, Page Up and Page Down a lot. Many 75% boards squeeze those keys into one column.

Are split keyboards better for programmers?

+

Many people with wrist or shoulder pain find them more comfortable. Expect a week or more to adjust, and longer on column-staggered boards.

Can I use a Windows keyboard on a Mac?

+

Yes. The Windows key works as Command and Alt as Option. To put Command next to the space bar, swap them in System Settings → Keyboard → Keyboard Shortcuts → Modifier Keys.
