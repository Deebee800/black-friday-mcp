What to look for in a laptop for coding

Check these six specs before you buy.

RAM
16 GB covers web development and scripting. 32 GB covers Docker, the Android emulator, Xcode and small local LLMs. 64 GB is for big local models or several VMs. Many thin laptops solder the RAM, so buy enough on day one.
CPU
Get 8 cores or more from a recent Intel Core Ultra, AMD Ryzen AI or Apple M-series chip. More cores cut compile and test times.
SSD
Get 1 TB. Docker images, SDKs and node_modules folders fill 512 GB quickly. Many Windows laptops let you swap the SSD later.
Screen
A 14-inch screen at 2560 x 1600 has about 216 PPI. At 1920 x 1200 it drops to about 162, and text looks softer. At a desk, an external monitor matters more than the laptop screen. See our guide to the best monitor for programming.
Battery and weight
Under 1.5 kg (3.3 lb) is easy to carry every day. Most 16-inch laptops weigh more. Battery claims come from video playback tests, and builds drain a laptop much faster.
Ports
Get at least one USB4 or Thunderbolt port for a dock or a 4K monitor. HDMI and USB-A save a dongle.

Which operating system?

Pick the one your target platform needs.

macOS

Xcode runs only on macOS. If you build for Apple platforms, our MacBook for programming guide compares the Air and the Pro.

Xcode · Homebrew · zsh

Windows with WSL2

Windows suits .NET and game development. WSL2 runs a real Linux kernel, so Linux tools and Docker work too.

WSL2 · Docker Desktop · Visual Studio

Linux

Most servers run Linux, so your laptop matches production. Lenovo ThinkPad and Dell XPS-class laptops have good driver support, and many models are Ubuntu certified. Check Wi-Fi and sleep before you buy.

Questions developers ask

How much RAM do I need for coding?

+

Measure what you use now. Open Task Manager on Windows or Activity Monitor on a Mac during a busy workday. If memory is close to full, get twice as much in your next laptop.

Is a gaming laptop good for programming?

+

Yes, if you can carry it. Gaming laptops have fast CPUs and good cooling, and many have RAM slots you can upgrade. An NVIDIA GPU helps with CUDA and local models. Many 16-inch models weigh over 2 kg (4.4 lb), and battery life is short.

Is a Chromebook OK for programming?

+

For learning and web work, yes. ChromeOS can run a Linux container with a terminal and VS Code. Most Chromebooks have 8 GB of RAM or less, so Docker and Android Studio run slowly. School-managed Chromebooks may have Linux turned off.
