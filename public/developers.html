Black Friday MCP for developers

A remote MCP server over Streamable HTTP with OAuth 2.1. No API key, nothing to install. Four read-only tools, US marketplace, prices in USD.

https://blackfridaymcp.com/mcp
Copy

Endpoint and transport

POST https://blackfridaymcp.com/mcp
MCP 2026-07-28, stateless; older stateless clients supported
Auth: OAuth 2.1 bearer token, scope shop:read

Unauthenticated requests get a 401 with a WWW-Authenticate challenge, so any compliant client discovers the flow on its own. Works with Claude, ChatGPT, Antigravity, Grok, Cursor, Codex, Claude Code, and any MCP SDK.

Authorization

Dynamic client registration at /oauth/register; client ID metadata documents accepted.
PKCE S256 required. Loopback redirect URIs with any port accepted.
Consent is one click and mints an anonymous install ID. No user accounts.
Access tokens last 30 days. Resource metadata at /.well-known/oauth-protected-resource/mcp.

Tools

All four are read-only. The exact JSON Schema is returned by tools/list.

search_deals
Live prices and discounts for a shopping question, in-stock items only.
query
string, required. 2 to 200 characters. What the shopper wants, in plain words.
max_price
number. Budget ceiling in US dollars, above 0 and at most 100000.
min_discount_percent
integer. 1 to 99. Only items Amazon marks at least this percent off.
category
string. A category id from get_trending_deals.
prime_only
boolean. Only Prime-eligible items.
check_deal
The price, the reference price, and a one-line verdict for one product.
asin_or_url
string, required. An amazon.com product URL or a 10-character ASIN.
get_trending_deals
Discounted, in-stock items in a category, ranked by how trustworthy the discount evidence is.
category
string. One of: tvs, headphones, laptops, tablets, smart-home, robot-vacuums, kitchen, air-fryers, toys, gaming, beauty, tools, fitness, baby, fashion.
max_price
number. Budget ceiling in US dollars.
gift_ideas
One to three gift ideas turned into in-stock products under a per-gift budget.
budget
number, required. Maximum price per gift, in US dollars.
ideas
array of strings, required. 1 to 3 ideas, 2 to 100 characters each.
recipient
string. Who it is for, e.g. "my dad who likes hiking".
occasion
string. e.g. "Christmas" or "birthday".

Response shape

content[0].text: human-readable block, links as markdown
structuredContent:
products[]: asin, title, brand, url, image_url, availability, deal{badge, ends_at, access},
price{amount, currency, display, as_of, display_with_time},
savings{percent, amount, reference_type, reference_label, reference_price, evidence_note}
notes[], hint, market, disclosure

Prices carry their fetch time inline. The disclosure block appears once per response. check_deal adds a one-line verdict. Links are Amazon's own URLs, untouched.

Limits

Per connection: 150 Amazon lookups per day, 10 uncached lookups per minute, about 60 requests per minute burst.
Cached answers do not count. Prices are cached up to 1 hour, everything else up to 24 hours.
Responses aim for under 5 seconds, with a hard ceiling of about 9 seconds.

Rules the server follows

Amazon links pass through exactly as vended. No shorteners, no added parameters.
No scraping. Everything comes from Amazon's Creators API.
No stored price history. Discount evidence comes from Amazon's own reference price for each item.
US marketplace only, prices in USD.

Try it from a terminal

curl -si -X POST https://blackfridaymcp.com/mcp
# → 401 with WWW-Authenticate: Bearer resource_metadata=…
