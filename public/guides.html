Connect Black Friday MCP to your assistant

Steps for Claude, Claude Duet, ChatGPT, Gemini, Grok, Grok Bot, Muse, Cursor, Codex CLI and Claude Code. Each takes about a minute and needs no Black Friday MCP account. The address is the same everywhere:

https://blackfridaymcp.com/mcp
Copy
Claude (web or desktop)−
1
Open Claude on the web or desktop. Go to Customize → Connectors.
2
Click + Add → Add custom connector. Name: Black Friday MCP. URL: https://blackfridaymcp.com/mcp.
3
Click Continue and keep the settings Claude detects. If a second Continue appears, click it too. Then click Add.
4
Click Connect if Claude shows it. A page opens with one button: Connect. Click it.
5
Start a new chat. Ask: "Black Friday deals on air fryers under $100?"
6
The first time, Claude asks permission to use a tool. Choose Always allow.
What you'll see: prices with the time they were fetched, a note on how real each discount is, and a link to each product on Amazon.
If Claude searches the web instead, add "use Black Friday MCP". Free plan: one custom connector.
Claude Duet (research preview)+
1
Duet has no connector settings of its own. It uses the connectors on your Claude account. Add Black Friday MCP in Claude on the web or desktop first, with the Claude steps above.
2
Open Duet on your phone or at claude.ai. Ask in chat: "Black Friday deals on air fryers under $100? Use Black Friday MCP."
3
If Duet doesn't use it, ask the same question in the Claude app.
Duet is a research preview for Pro, Max and Ultra plans in the US, by invitation. Team and Enterprise plans don't include it. Scheduled Duet runs may not reach custom connectors, so ask in chat.
ChatGPT (web, Plus and up)+
1
Click your name → Settings → Apps & Connectors.
2
Open Advanced and turn on Developer mode.
3
Click Create. Name: Black Friday MCP. URL: https://blackfridaymcp.com/mcp. Save.
4
Start a new chat. Ask: "Black Friday deals on air fryers under $100?"
What you'll see: ChatGPT shows it is using the connector, then answers with prices, fetch times, and Amazon links.
If it searches the web instead, add "use Black Friday MCP".
Gemini (through Google Antigravity)+
1
The Gemini app does not accept custom connectors yet. Install Google Antigravity and sign in with your Google account.
2
Open MCP servers → Manage MCP servers → View raw config.
3
Add this entry and save:
{ "mcpServers": { "blackfriday": { "serverUrl": "https://blackfridaymcp.com/mcp" } } }
4
In the agent chat, ask: "Black Friday deals on air fryers under $100?"
What you'll see: blackfriday in the MCP servers list with four tools.
Grok (web)+
1
Open grok.com/connectors → New Connector → Custom.
2
Paste https://blackfridaymcp.com/mcp. If Grok asks for a name, use Black Friday MCP. Add the connector.
3
A page opens with one button: Connect. Click it.
4
Ask: "Black Friday deals on air fryers under $100? Use Black Friday MCP."
What you'll see: each product as a card with a photo, the price, and a link to Amazon.
Grok Bot (desktop app or chat)+
Desktop app
1
Open Connect apps → Add a custom connector.
2
Name: Black Friday MCP. Type: Remote HTTPS. Server URL: https://blackfridaymcp.com/mcp. Click Add plugin.
3
Click Authenticate. A page opens with one button: Connect. Click it within about 10 minutes.
4
In a chat, type @ to attach Black Friday MCP. Ask: "Black Friday deals on air fryers under $100?"
Any chat with Grok Bot, on desktop or phone
1
Send this message:
Add this MCP server: https://blackfridaymcp.com/mcp
2
Confirm when Grok Bot asks, then tap Authorize. A page opens with one button: Connect. Tap it.
3
Ask: "Black Friday deals on air fryers under $100?"
Grok Bot needs a Premium, Super or Ultra plan, a paid Cursor plan, or a linked SuperGrok or X Premium+ account. It is built with Cursor, so the Connect page may name Cursor.
Muse (Meta)+
1
Open the Muse app or muse.ai and start a new chat.
2
Send this message:
Create a Custom Connector for a new remote MCP server, then connect to it: Name: Black Friday MCP. Transport: remote streamable HTTP. URL: https://blackfridaymcp.com/mcp. Auth: OAuth.
3
Muse shows a card to add the connector. Add it, then confirm again on the notice that Meta does not review custom connectors. On iPhone, confirm once more.
4
A page opens with one button: Connect. Tap it.
5
Ask: "Black Friday deals on air fryers under $100?"
Muse works in the US, Canada, Japan, Singapore and Australia. The Meta AI app can't add custom connectors.
Cursor+
1
Click Add to Cursor, or open Settings → MCP → Add new MCP server and paste:
{ "mcpServers": { "blackfriday": { "url": "https://blackfridaymcp.com/mcp" } } }
Add to Cursor
2
Approve the connection when Cursor asks. A browser tab opens with one button: Connect.
3
In the agent chat, ask: "Black Friday deals on air fryers under $100?"
What you'll see: blackfriday under MCP with four tools.
Codex CLI+
1
Run codex mcp add blackfriday --url https://blackfridaymcp.com/mcp
2
Start Codex and approve the connection. A browser tab opens with one button: Connect.
3
Ask: "Black Friday deals on air fryers under $100?"
Claude Code+
1
Run claude mcp add --transport http --scope user blackfriday https://blackfridaymcp.com/mcp
2
Type /mcp → blackfriday → Authenticate. A browser tab opens with one button: Connect.
3
Ask: "Black Friday deals on air fryers under $100?"
What you'll see: /mcp shows blackfriday as connected with four tools.

Not working?

If your assistant searches the web instead, add "use Black Friday MCP" to your question.
If it cannot reach the server, remove the connector and add it again.
Prices and links are for Amazon.com (US) only.
